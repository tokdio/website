# Tokdio website

The public landing page for [Tokdio](https://tokdio.github.io/website/).

Tokdio turns business outcomes into shipped, sold, and supported software while people retain authority over direction, budgets, approvals, and evidence.

## Local preview

Serve the repository root with any static HTTP server, then open `index.html`.

```sh
python3 -m http.server 4173
```

The site is deployed from the `main` branch through GitHub Pages. The intended custom domain is `tokdio.com`; DNS cutover is managed separately from this repository.
